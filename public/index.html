Models

Which Claude model and how much thinking each action uses. Bigger models and higher effort are smarter but slower and use more of your subscription limits. Changes apply to the next run, no restart needed.

Presets:

“CLI default” = whatever model Claude Code uses when you run claude yourself. xhigh / max effort need a recent Claude Code. Custom accepts any model name, e.g. claude-opus-5-5 or sonnet[1m].

Languages

What language Claude writes in. “Same as the posting” follows the language of the job posting (or the form). A one-off language for a single CV can be picked in the Generate box of a job.
