# Job Hunter

Локальное веб-приложение для поиска вакансий. Под капотом вызывает Claude Code (`claude -p`),
поэтому работает в рамках твоей подписки Claude, без отдельной оплаты API.

Что умеет:
- **Find new jobs** — Claude ищет открытые вакансии по твоему профилю, отсеивает дубли и закрытые, ставит оценку соответствия 0–100.
- **Extra sources** — дополнительные (необязательные) сайты и Telegram-каналы с вакансиями (`@channel`, `t.me/channel` или ссылка на сайт/поиск).
  «Find new jobs» проверяет их в первую очередь, кнопка «Search only these sources» ищет только по ним.
  Каналы — только публичные: Claude читает последние посты через веб-превью `t.me/s/<канал>`. Список лежит в `data\sources.json`.
  Для сайтов приложение само собирает ссылки на вакансии со страницы и из sitemap (на сайтах вроде Hitmarker список
  рисуется JavaScript'ом и Claude видит пустую страницу) и отбирает их по словам из блока **Filter** на той же вкладке:
  «Look for» — что искать в ссылке, «Hide» — что скрыть (такие вакансии убираются и из результатов любого поиска).
  Фильтр хранится в `data\source-filter.json`.
- **Зарплата** — у каждой вакансии есть блок с зарплатой. Если в вакансии указана вилка, показывается она (зелёный бейдж в списке).
  Если цифр нет, Claude ищет данные о зарплатах (Glassdoor, Levels.fyi, Djinni и т.п.) и показывает примерную вилку с пометкой
  «estimate», пояснением и ссылками на источники (в списке — бейдж «≈ …»). Для старых вакансий оценка появится после «↻ Refresh».
- **Добавить вакансию вручную** — вставь ссылку или текст вакансии в поле сверху.
- **People to contact** — кнопка «Find HR & referrals» в окне вакансии. Claude ищет (в основном на LinkedIn, через поиск,
  плюс сайт компании и прочий интернет) рекрутера или нанимающего менеджера под эту роль, проверяет, есть ли у компании
  реферальная программа, и подбирает 3 сотрудников, которых можно попросить о рефералке (инженеры похожего профиля,
  желательно с чем-то общим с тобой). В приоритете люди из города / офиса вакансии, потом из той же страны:
  у каждого указано, где он работает, и бейдж «job location» / «same country» / «other location», люди из других мест
  идут в конце списка. У каждого — ссылка на профиль, почему именно он, уверенность и готовая записка
  для запроса в LinkedIn (до 300 символов) с кнопкой «Copy message». Ничего не отправляет. Результат хранится в `jobs.json`.
- **Статусы и заметки** — New → Interested → Applied → Interview → Offer / Rejected / Skipped.
  Дата отклика запоминается при первом переходе в Applied (бейдж «applied 5d ago» в списке).
  При Skipped можно написать причину («Unity only», «US residents only») — она добавится в профиль
  в список «Not interested in», и следующие поиски будут пропускать такие вакансии.
- **Generate** — резюме под конкретную вакансию (ATS-ключевые слова, без выдуманного опыта) + cover letter + список требований, которых у тебя нет.
- Редактирование, копирование, скачивание .md и **Print / PDF** для резюме.
- **Open & fill form** — открывает страницу отклика в отдельном окне Edge/Chrome и заполняет поля (имя, контакты,
  ответы на вопросы, прикрепляет PDF резюме). Ничего не отправляет: заполненные поля обведены жёлтым, остальное и Submit — ты сам.
  - Если форма на другой странице — вставь её в поле **Application form link** (запоминается для вакансии).
  - **Try to auto apply** — если адаптированного CV ещё нет, сначала делает его (1–3 минуты), потом открывает страницу отклика, заполняет форму, ставит галочки согласия (обработка данных, privacy policy, terms — но не рассылки) и **нажимает Send**. Статус вакансии становится Applied. Если обязательные поля остались пустыми, кнопку отправки не нашёл или сайт не подтвердил отправку — показывает ошибку. После обновления кода перезагрузи расширение (кнопка ↻ на brave://extensions).
  - **С расширением** (рекомендуется) форма заполняется прямо в твоём браузере, с твоими логинами. Установка один раз:
    1. Открой `brave://extensions` (в Chrome — `chrome://extensions`, в Edge — `edge://extensions`).
    2. Включи **Developer mode** (режим разработчика).
    3. **Load unpacked** → выбери папку `extension` внутри job-hunter.
    4. Обнови страницу приложения. Под кнопками появится «Fills in this browser (extension connected)».
    Расширение работает только вместе с открытой страницей приложения и ничего никуда не отправляет, кроме твоего локального сервера.
  - **Без расширения** форма открывается в том же браузере, в котором открыто приложение (Brave, Chrome, Edge, Opera, Яндекс, Vivaldi;
    Firefox не поддерживается). Другой браузер можно задать в `config.json`: `"applyBrowserBin": "C:\\...\\brave.exe"`.
  - Это отдельное окно со своим профилем (`data\.browser-profile-<браузер>`) — браузер не даёт управлять основным профилем.
    Залогинься там один раз в LinkedIn и т.п., логины сохранятся.

## Требования

- Node.js 18+ (у тебя уже есть, раз установлен Claude Code через npm).
- Claude Code, в котором ты залогинен своей подпиской: в терминале `claude` должен запускаться без ошибок.

## Запуск

1. Распакуй папку куда удобно, например `C:\Users\<ты>\Projects\job-hunter`.
2. Дважды кликни **start.bat** — откроется `http://localhost:4317`. Окно консоли не закрывай, пока пользуешься приложением.
3. Вкладка **Resume & profile**: резюме уже заполнено из твоего Google Doc, профиль — из прошлых настроек поиска. Проверь и поправь.
4. Нажми **Find new jobs**. Первый поиск идёт 3–15 минут.

## Настройки (config.json)

| Поле | Что делает |
|---|---|
| `port` | Порт веб-страницы (по умолчанию 4317). |
| `claudeBin` | Путь к `claude`, если он не в PATH. |
| `models` | Модель для каждого действия: `search` (поиск), `analyze` (разбор вакансии), `tailor` (CV + письмо), `people` (поиск HR и рефералов). Варианты: `haiku`, `sonnet`, `opus`. По умолчанию везде `sonnet`. |
| `effort` | Насколько долго модель думает: `low`, `medium`, `high`. По умолчанию везде `medium`. |
| `perplexity` | Использовать Perplexity из твоего аккаунта claude.ai при поиске (`true`/`false`, см. ниже). |
| `mcpConfig` | Путь к JSON с MCP-серверами (например, Perplexity, см. ниже). |
| `extraAllowedTools` | Какие инструменты MCP разрешить, например `["mcp__perplexity"]`. |
| `maxJobsPerSearch` | Максимум вакансий за один поиск. |
| `maxParallel` | Сколько запусков Claude идут одновременно (по умолчанию 2). Поиск, заполнение формы и синхронизация резюме — всегда по одному. |
| `searchTimeoutMinutes` | Таймаут поиска. |
| `timeouts` | Таймаут в минутах для остальных действий: `analyze`, `tailor`, `people`, `apply`, `resume`. |
| `resumeSyncOnStart` | Проверять резюме на Google Drive при каждом запуске (`true`/`false`). |
| `autoSearch` | Автопоиск, пока сервер запущен: `enabled`, `everyHours`, `maxAgeDays`, `sourcesOnly`. |
| `languages` | Язык текстов: `cv` (резюме), `letter` (письмо), `messages` (записки в LinkedIn), `forms` (ответы в формах). `"auto"` — язык вакансии, иначе название языка, например `"English"`. По умолчанию резюме и формы на английском, письмо и записки — на языке вакансии. Для одного CV язык можно выбрать в «Options» над кнопкой Generate. |
| `applyBrowserBin`, `browserBin`, `applyBrowserPort` | Браузер для заполнения форм, браузер для PDF, порт отладки браузера форм. |

Всё это можно менять на вкладке **Settings** в приложении: модели и effort для каждого действия (плюс пресеты
Economy / Balanced / Best quality / Maximum), таймауты, автопоиск, резюме, браузеры, путь к Claude с кнопкой
«Test Claude» и статистика запусков (`data\usage.json`). Изменения применяются сразу, кроме порта — для него нужен ↻ Restart.

## Perplexity

Поиск вакансий использует Perplexity вместе со встроенными WebSearch/WebFetch: Perplexity находит свежие вакансии,
а Claude потом открывает каждую через WebFetch и проверяет. При разборе вакансии и генерации CV Perplexity
помогает, если страница вакансии не открывается.

Работает через коннектор Perplexity в твоём аккаунте claude.ai (тот же, под которым залогинен Claude Code),
поэтому API-ключ не нужен. Выключить: `"perplexity": false` в `config.json`.

Если коннектора в claude.ai нет, можно подключить Perplexity по своему API-ключу (платно, отдельно от подписки):

1. Скопируй `mcp-perplexity.example.json` в `mcp-perplexity.json` и вставь ключ.
2. В `config.json`: `"mcpConfig": "mcp-perplexity.json"`, `"extraAllowedTools": ["mcp__perplexity"]`.

## Где лежат данные

Всё в папке `data\`: `jobs.json` (вакансии), `resume.md`, `profile.md`, `applications\<id>\` (резюме и письма под каждую вакансию).
Это обычные файлы — можно бэкапить или класть в git (в `.gitignore` папка data исключена, т.к. там личные данные).

## Важно

- Сервер слушает только `127.0.0.1` — с других устройств он недоступен. Не выставляй его в интернет: он работает от твоей подписки.
- Каждое действие — это отдельный запуск `claude -p`. Одновременно идут до `maxParallel` (2) запусков; короткие задачи (разбор ссылки, CV, форма) встают в очередь раньше поиска. Поиск расходует заметную часть лимитов, адаптация CV — немного.
- Приложение отправляет отклик только по кнопке **Try to auto apply**; всё остальное отправляешь ты сам.
- Claude может ошибаться в оценке вакансий — открывай ссылку перед откликом и перечитывай резюме перед отправкой.
